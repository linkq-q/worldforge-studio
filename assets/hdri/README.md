# Shared HDRI Library

This directory is the read-only, Git LFS-managed panorama library distributed with WorldForge Studio.

- Supported files: `.exr` and `.hdr`.
- The editor also reads `data/map-editor/hdri/`; local files override a shipped file with the same name.
- HDRI classifications created in developer mode are saved to the local data directory, never written back here.
- Keep source/license metadata with any future library refresh before publishing it.
