# 地图视觉生成后续任务书

## 当前已完成的 AI 生成范围

- 一键生成与 Refine 共用原子 `MapOperation[]` 预览/确认流程。
- 默认生成新资产；用户可按次允许复用旧资产，并可调本次新资产上限。
- 构图区域持久化为 `visualSemantics.zones`，地表色差、湿岸、草地接触退让和局部灯光由地图内容自动重算。
- 草地接触退让只作用于渲染派生结果，不覆盖已保存的手工密度。
- 自发光与火焰模型可派生局部点光；当前屏幕内最多 8 个。

## 后续手动编辑

1. 增加区域语义编辑器：可移动中心、调整半径、增删标签和强度，不新增第二套区域对象。
2. 为 AI 派生参数增加“手调覆盖/锁定”层；重新生成时优先保留锁定值，其余参数自动重算。
3. 增加派生结果检查视图：分别查看地表语义、湿岸、草地退让和局部灯候选，但不增加阻断确认或警告弹窗。
4. 支持在 Refine 指令中精确引用区域 ID，让 AI 只修改指定区域及其关系。

## 暂缓项

- 系统化资产变体暂不做；当前每个语义资产家族生成一个新资产。
- 旧地图兼容迁移暂不做。
- 树木、水体数量不设产品级限制，只保留现有事务与地图边界兜底。
- 局部灯性能优化后置；未来根据真实场景数据决定是否扩展 8 灯上限、分簇或烘焙。
- 金样与视觉前后对比由人工验收后再补。

## 架构约束

- 地图区域、结构化水体、对象和材质标签属于地图阶段；最终调色、Bloom、雾和渲染方案仍属于渲染阶段。
- 派生效果必须由已保存地图确定性重建，不能额外保存一份容易漂移的结果。
- 手工值与 AI/派生值必须有明确来源；自动重算只能覆盖未锁定的派生值。
