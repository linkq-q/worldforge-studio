# 地图设计评估约定

本文记录截至 2026-10-07 用户在本轮讨论中确认的判断依据。它指导开发对比与模型反馈，不建立新的审美分数或自动通过门槛。

## 当前优先级

地图需要让人看出它如何作为一个场所使用，而不只是地形上分布着树和房屋。

- 总览时能够辨认主要区域，以及区域之间的组织关系。
- 进入近景后，物体、地面和空间安排能够说明这个区域的用途。
- “果园”“集市”等名称是设计意图；名称或对象数量不能代替可见的实现。
- 路线与目的地一起考虑，并依据提示词支持自由探索或明确目标。

当前首要失败是缺少理由的大面积绿色空地，以及没有整体规划、功能区分和相应内容的地图。改善不等于把所有空地填满：荒山、沙漠、林间空地、视野开敞或其他有明确作用的留白均可成立，是否合适取决于本次要求及周边关系。

用户已认可当前植物分布明显改善，应保留有效的林团和层次。精雕噪声、局部装饰及更高模型精度暂居次要位置；不能用这些改动替代功能区与整体组织。

## 分开评估三个对象

| 对象 | 要回答的问题 | 可用证据 |
| --- | --- | --- |
| Harness 离线对比 | 新环境与工具是否帮助模型完成原任务，减少遗漏并保留已有优点？ | 同条件自主生成记录、工具使用与失败记录、原始最终草稿及人工对比 |
| 模型单次动作 | 这次观察或修改是否支持它声明的目的，是否越出范围或破坏已有结果？ | 动作目标、实际操作、版本和位置、前后事实、工具结果 |
| 地图作品 | 总览能否辨区、近景能否理解用途，路线和内容是否服务本次场景？ | 可检查的地图、固定视角总览和近景、用户判断 |

单次工具成功不代表作品成功；作品暂时好看也不证明工具稳定。结构测试、浏览器正常显示与用户视觉认可分别报告。

## 同一初始请求的自主结果对比

1. 固定初始地图、提示词、可用资产、种子、模型及请求参数，并记录双方实际使用的代码版本。
2. 让每个版本从同一初始条件开启自己的持续会话。一次用户请求后，由模型自主观察、执行和结束；不要由开发者逐轮指定布局答案。
3. 保留模型原始动作、执行错误、工具反馈、最终代码和最后完整草稿。模型在同一会话内根据反馈修改属于本次自主过程。
4. 不能在结束后悄悄修场景再当作原始结果；若需人为修正，应另存并明确标为人工介入后的版本。
5. 使用相同相机、显示尺寸和可比渲染条件拍摄总览，再拍能判断功能用途的近景。比较色彩能力时，明确各自是否已进入并应用待审渲染草稿。
6. 等待场景加载完成再截图。缺失内容、失败或预算暂停均保留并标明，不能挑选局部截图掩盖未完成区域。
7. 记录耗时、模型动作数、资产任务数、失败和停止原因。这些是成本与稳定性事实，暂不据此设定合格阈值。

截图只用于开发和人工验收，不是生产生成流程的必需输入。结构化观察仍应让模型在没有相机回传的情况下继续完成任务。截图、运行记录及运行数据放在仓库外，不进入代码提交。

## 给模型的反馈如何写

反馈围绕当前请求和动作目标，不把某种布局模板当成所有地图的答案。

- **事实**：说明测量或读取到了什么，带 map/base/draft 版本、实体 ID、位置、执行阶段和采样或近似范围。
- **推断**：说明事实为什么可能影响当前目标，标出推断依据；例如“声称果园，但目前只有与周边林地相似的树群，用途可能难以辨认”。
- **未知**：保留尚未观测或当前工具无法判断的内容；不要把未知写成零，也不要把语义标签写成视觉证据。
- **可行动性**：提供可读的 tool evidence 引用、相关对象或区域，以及必要的 requery 入口。几何改变后，旧位置与旧版本的结果不能继续当作当前事实。
- **保留项**：说明哪些已被用户认可或本轮无需更改，避免为了回应一个问题而重做整张地图。

例：若任务是让果园用途可辨，反馈先列出该区域实际存在的树、地面组织、设施及其位置，再区分“已有内容”与“还不能确认其用途”。模型自行决定是否需要成组树列、生产设施、路径或别的表现方式；工具不强制一套果园模板。

反馈不输出全局审美总分，不把每个诊断都转成强制修复。容量、格式、有限数值、引用和事务版本等现有结构安全边界仍照常执行。

## 路线观察边界

保持当前路径观察粒度：路线几何、端点关系、坡度和水域等事实可帮助模型判断设计。它们不构成逐路步行可达验收。

不新增“每条路都必须能走”的门槛。其他符合场景设定的通过方式可以成立；也不要求为证明地图而顺带实现玩家能力或玩法系统。无法确认的通过方式应说明边界，而不是断言地图已完整可玩或一律判为失败。

## 已定与待议

已定的是区域可辨、用途可理解、整体组织优先，以及保护已认可元素的反馈方式。没有要求固定建筑数量、区域数量、植被覆盖率或统一路线形态。

本轮开发验收已授权最多 10 次真实上游请求，规划、资产及实际发出的重试合计；这是本轮限制，不是所有用户的永久预算。一般产品的停止条件、可接受耗时、费用策略和比较样本数量仍待讨论。现有运行预算是执行限制，不是作品质量标准；达到预算暂停不能报告为任务完成。
