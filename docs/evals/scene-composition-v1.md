# Scene Composition v1 验收

## 金样提示词

> 生成一张中型、偏动森式的森林场景：主森林有明显疏密层次，中间留出林间空地，旁边有一座自然池塘，远处有一间温暖的小木屋或营地。整体可以自由浏览，木屋是视觉焦点，森林、池塘和空地之间要自然过渡，树、岩石和小景的尺度协调，不要一半空白一半堆满树。

## 自动验收

`tests/sceneComposition.test.ts` 固定一份符合该提示的导演计划，验证执行层：

- 同一地图 seed 和同一计划得到完全相同的操作与坐标；
- 包含主森林、池塘、林间空地、木屋/营地四种本次由 AI 决定的区块；
- 区块覆盖率大于 55%，物体数大于 20，且存在结构化湖泊；
- 普通物体不进入负空间或水体，多个焦点资产逐个避让；
- 输出仍是普通 `MapOperation[]`，可应用到地图并继续编辑；
- 不生成 `reference.set`，渲染建议只写入 `renderPromptSuggestions`。

## 模型验收

同一提示至少运行 3 次，每次保存导演计划、专家调用、合成审查、lint、最终地图截图和耗时。每次按以下维度人工打分 0-2；总分至少 9/12，且任一硬失败为不通过：

1. 构图主次：木屋/营地可识别为焦点，其他区块不抢夺焦点。
2. 空间完整：不存在明显的半图空白或单一区域无规律堆积。
3. 过渡自然：森林到空地、森林到池塘边界没有生硬圆环。
4. 尺度协调：树、岩石、小景、木屋的相对尺寸可信。
5. 水陆融合：池塘位于地形中，岸边没有大面积露底或植被穿水。
6. 可编辑性：接受预览后，可单独选择对象、Refine 地图，并确认后进入渲染阶段。

硬失败：生成中断、超出同模式资产约束、出现不可应用事务、地图确认前自动应用渲染、普通链路加入玩法/出生点规划。

## Trace 记录

一次 trial 的最小记录包括：原提示、地图 seed/尺寸/建模模式、`suggestion.composition`、生成资产 ID、最终 `MapOperation[]` 数量、lint 诊断、用户是否接受。不能只看最终文字回复；验收对象是落地后的地图状态。
